## 已知边界

- 单点测量要求 Zolix `pixels_to_waves` 返回与像素数相同长度的波长，否则测量失败（会关激光并留下记录）。真机上这个调用是否稳定还没有单独确认。
- WayneLabs `identify` 的首个响应可能分包，解析尚未修复；单点元数据里 identify 失败只记录 `status_error`，不让测量失败。
- 物镜转盘（COM5）、光路切换（COM16）、半波片（COM17）还没有接入；托盘扫描回执中的 `measurement_ready` 是外部程序或操作员的确认，不是硬件读回。
- 后端只支持单进程、本机可信操作员，没有身份认证和操作审计；不能和真机命令行或厂家软件同时控制硬件。
- 软件急停依赖进程和串口正常工作；原生 SDK 卡死或进程被强制结束时只能用物理急停。
- 任务记录文件损坏时后端拒绝启动并保留原文件（仍会先尝试关闭光源）；不要直接删除记录文件来绕过。
- 厂家 SDK 已移出 Git 索引，但仍在历史提交中；如果远程仓库公开且 SDK 不允许分发，需要改写 Git 历史。
- CCD 控温和宇宙射线去除尚未实现。
