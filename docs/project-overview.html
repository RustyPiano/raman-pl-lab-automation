暂缓

实机测试清单

哪些必须上实验室机器，哪些可以继续在本地做。

必须上实机

  1. Phase 1 设备验收：stage identify/move/home、devices doctor、spec status/init/set、camera status/capture、workflow single。
  2. M1 光源验收：读取 Reg1、Reg17-Reg21、目标通道频率/占空比；打开和关闭激光/白光后读回确认。
  3. 安全失败路径：读回失败、频率/占空比不匹配、非目标通道开启时拒绝继续，并提示人工确认激光关闭。
  4. M2 完成后：小网格 Mapping、X/Y set-zero 或 home、软限位、manifest、resume。

本地还能继续做

  1. M2 dry-run/simulated 实现：不需要真机，可以先按计划完成测试驱动开发。
  2. 配置和安全校验：grid 对齐、软限位、real 模式必须 `--real --yes`。
  3. manifest/resume：文件写入、失败记录、跳过已完成点可以纯本地验证。
  4. M3 数据处理：多数是离线算法，可用样例数据先开发。
